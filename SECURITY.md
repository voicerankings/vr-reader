# Security Policy

## 🛡️ Supported Versions

We issue security patches for the latest release version of **VoiceRankings Reader**.

| Version | Supported |
| :--- | :--- |
| Latest Main | ✅ Yes |
| < 1.0.0 | ❌ No |

---

## 📩 Reporting a Vulnerability

We take the security of **VoiceRankings Reader** seriously. If you discover a security vulnerability, please **do not open a public GitHub issue**.

### How to Report Responsibly:

1. **Email Us Privately**: Send an email detailing the issue to **security@voicerankings.com** or contact us via [VoiceRankings.com](https://voicerankings.com).
2. **Include Details**:
   - Description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact (e.g. storage access, API key exposure risks).
3. **Response Timeline**:
   - We will acknowledge receipt of your report within **48 hours**.
   - We will provide an estimated timeline for a fix and coordinate a public disclosure date once patched.

Thank you for helping keep VoiceRankings Reader safe for everyone!
